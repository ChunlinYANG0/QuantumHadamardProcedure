# QuantumHadamardProcedure
Resource-Tunable Quantum Implementation of Nonlinear Element-Wise Transformations

The circuit of state preparation and block encoding is constructed by using the binary-tree method in the article "Zexian Li, Xiao-Ming Zhang, Chunlin Yang, Guofeng Zhang. Binary Tree Block Encoding of Classical Matrix. IEEE Transactions on Quantum Engineering, 2025, 7: 1-18." (code in https://github.com/zexianLIPolyU/BITBLE).
